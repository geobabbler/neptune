**2. Names in OSM** — *Spatialists*
OpenStreetMap volunteers have now mapped 115 million place names worldwide, and a post on the OSM blog explains how the project handles local, official, and multilingual naming. Unlike some large commercial map providers, OSM's default map shows everyone the same local name rather than a localized substitute.
→ [Read it](https://spatialists.ch/posts/2026/09/26-names-in-osm/)
